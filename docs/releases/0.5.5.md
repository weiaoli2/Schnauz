# Schnauz 0.5.5 — Your projects. Your files. Your terminal.

Schnauz is a native Mac file manager built around projects. Keep the right files,
places, terminal and tasks together, then switch projects without rebuilding your
workspace every time.

**[Explore Schnauz on TechGuyZone](https://techguyzone.com/apps/)**

## A workspace that follows your project

- **Project-specific browsing:** each project remembers its favourites, pinned
  files, tabs and layout. Shared Common places stay close across projects.
- **A seamless interactive terminal:** work below your files in a persistent
  shell. Local folders can sync at an idle prompt; running editors, Codex and
  other CLI tools keep control. Start a new terminal directly in an SSH folder
  and keep existing sessions intact while browsing elsewhere.
- **Paste a path and get there:** paste a folder path to open it, or a file path
  to open its folder and select the file. The full path is editable with ⌘L.
- **Todoist in context:** view, add and complete tasks in the matching project.
  Project names link your workspaces; task creation stays locked to its project,
  while updates run in the background.
- **Compact native file tools:** List/Icons views, saved columns and widths,
  resizable text/media previews, focused filename/content search, cloud badges,
  optional Nextcloud actions and on-demand Disk Usage.

Built with Rust and GPUI, with native Mac icons and menus. Expensive searches
and storage scans start on demand; ordinary browsing does not recursively
calculate folder sizes or build a home-folder index.

## Refinements in this preview

- **Visible copy progress in the footer:** a compact bar, real percentage,
  current-file information and Cancel for local/SSH copy jobs. Network percentages
  describe the current file. Transfers stay in the background without covering
  the file list or shifting the layout.
- **Steady drag targets:** a hovered tab stays blue even when the mouse stops.
  Hold over a tab or folder to open it during a drag. Local dragging moves;
  Command copies with native feedback.
- **Persistent SSH work:** folder/favourite navigation and pasted local paths
  retain existing terminals. SSH follows terminal → browser; browsing never
  sends directory-change commands into a running SSH shell.
- Shared Common shortcuts, editable paths, native resizing, readable Todoist
  rows and the compact native task composer are included in this release.

## Download and install

Requires **macOS 14 Sonoma or later**. Choose **arm64** for Apple Silicon (M1 and
newer) or **x86_64** for Intel, then drag Schnauz.app from the DMG into Applications.
SHA256SUMS.txt covers both installers and the exact MPL component-source archive.

This is an **early prerelease**, signed with an **Apple Development** certificate;
it is **not Apple-notarized**. Read the repository's security/installation notes
for checksum verification and first-launch guidance. Intel validation on the
build Mac uses Rosetta, not a physical Intel machine. The test suite passes 82 Rust tests plus offline native, composer, layout and
drag checks. Transfer tests use an actual local SFTP server with disposable files.
Live account/server interoperability remains part of ongoing user testing.

Todoist and Nextcloud are optional. Their credentials stay in macOS Keychain;
no live tokens, app settings or signing keys are included in this release.
